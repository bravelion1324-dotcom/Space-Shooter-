# 8-BIT SPACE SHOOTER 👾🚀

A retro 8-bit arcade space shooter made in Python.

### About
Classic top-down space shooter. You control a spaceship, shoot incoming enemies, and try to get the highest score. Pure 8-bit vibes.

### Features
- 8-bit pixel art style
- Player movement + shooting
- Enemy waves
- Score system
- Game Over / Restart
- Retro sound effects (optional)

### How to run it
This is a **.py file, not an APK**. Made to run on mobile Python launchers.

1. Install **Pydroid 3** or **PryamIDE**
2. Install requirements:
3. Open the py file of space shooter and hit Run

### Built With
- Python
- Kivy - for game window & controls

### Controls
- Touch / Drag to move
- Tap button to shoot
- (or keyboard arrows + space if on PC)

### Goal
Survive as long as possible and beat your high score.

Simple, retro, fun Python project.
